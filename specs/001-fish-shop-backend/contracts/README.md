# API Contracts — Conventions

All endpoints are under the versioned prefix `/api/v1/` (constitution §4).
Full OpenAPI/Swagger/ReDoc is auto-generated by FastAPI from these routes at
runtime (constitution §43) — the files in this directory are the
human-authored contract this implementation must satisfy, one file per
resource group, matching `spec.md`'s functional-requirement groups.

## Auth column values

- **Public** — no token required.
- **Customer** — any authenticated user (customer or admin).
- **Owner** — authenticated user, and the request is scoped/filtered to resources they own (enforced in the service layer, not just the route).
- **Admin** — authenticated user with `role = admin`.

## Shared error format (constitution §20/§36, spec.md FR-055)

Every non-2xx response body:

```json
{
  "error": {
    "code": "PRODUCT_NOT_FOUND",
    "message": "The requested product was not found."
  }
}
```

Standard `code` values used across all resource groups (not exhaustive —
each contract file adds domain-specific codes):

| HTTP | code | Meaning |
|---|---|---|
| 400 | `VALIDATION_ERROR` | Request failed schema/business validation |
| 401 | `UNAUTHENTICATED` | Missing/invalid/expired token |
| 403 | `FORBIDDEN` | Authenticated but not authorized for this resource |
| 404 | `NOT_FOUND` | Resource does not exist (or not owned by caller) |
| 409 | `CONFLICT` | Duplicate resource / state conflict (e.g. already reviewed) |
| 422 | `INSUFFICIENT_STOCK` / `SLOT_UNAVAILABLE` | Domain-specific availability conflict |
| 502 | `EXTERNAL_SERVICE_ERROR` | An external dependency (exchange-rate provider) failed |
| 500 | `INTERNAL_ERROR` | Unexpected failure; body never includes a stack trace |

## Pagination envelope (FR-015)

Every list endpoint accepts `?page=<int, default 1>&limit=<int, default 20>`
and returns:

```json
{
  "items": [ /* ... */ ],
  "page": 1,
  "limit": 20,
  "total_items": 137,
  "total_pages": 7
}
```

## Money shape (FR-018, FR-022)

Every price-bearing response includes:

```json
{
  "base_price": "20.00",
  "base_currency": "USD",
  "display_price": "5610.00",
  "display_currency": "PKR",
  "exchange_rate": "280.5000"
}
```

Decimal values are serialized as strings to avoid client-side floating-point
re-introduction of the precision problem FR-022 forbids server-side.
